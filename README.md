# Keep the Door Locked Wiki

Independent, fact-checked beginner guides for **Keep the Door Locked [Anomaly]** on Roblox.

Production domain: [keepthedoorlocked-wiki.wiki](https://keepthedoorlocked-wiki.wiki)

## Site scope

- Beginner-first onboarding and first-night checklist
- Core gameplay loop
- Common mistakes and recovery habits
- Ending and encounter clues sourced from Roblox badge data
- FAQ and transparent source notes

This is a fan-made guide and is not affiliated with Roblox or the game's creator, Hotel Room Services.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm test
npm run build
```

The app uses Next.js App Router and is configured for Vercel production deployment.
